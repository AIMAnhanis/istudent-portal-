i-Student Portal
Student management portal for the IMS566 course.

Project Description
This project is a student portal prototype designed to facilitate students in managing assignments, downloading lecture notes, viewing class timetables, and updating student profiles.

Features Included
Dashboard: Displays a summary of pending tasks and visual data (Task progress chart).

Assignments: Tracks assignment statuses (Overdue, Pending, Submitted).

Notes & Resources: Allows downloading of lecture materials by subject.

Timetable: Weekly class schedule overview.

Profile: Displays student personal information and academic records.

Instructions to Test Login
Access the live website: https://AIMAnhanis.github.io/istudent-portal-/index.html

Click the "Login" button on the portal page to enter the Dashboard.

Frameworks/Libraries Used
Bootstrap 5: For responsive front-end design.

Chart.js: For data visualization on the Dashboard.

Vanta.js: For background effects on the Login page.
